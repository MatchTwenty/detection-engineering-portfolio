# Incident Response Portfolio

This repository contains professional-grade incident response (IR) documentation, workflows, templates, and forensic triage artifacts. It demonstrates structured, repeatable, and defensible IR processes aligned to modern enterprise and cloud environments.

## Contents

- **case-workflows/** — Step-by-step workflows for common incident types  
- **forensic-triage/** — Endpoint and cloud forensic triage checklists  
- **chain-of-custody/** — Evidence handling and integrity documentation  
- **evidence-collection/** — Scripts and procedures for collecting artifacts  
- **cloud-incident-response/** — Azure/M365 IR workflows  
- **reporting/** — IR report templates and executive summaries  
- **playbooks/** — SOAR-style response playbooks  
- **templates/** — Reusable IR artifacts (severity matrix, escalation matrix)

See `ir-index.md` for a full index of all IR artifacts.

# Insider Threat Workflow

## Objective
Investigate data exfiltration, anomalous behavior, or misuse of access.

## Steps

### 1. Initial Triage
- Review DLP alerts
- Check file access logs
- Validate user activity

### 2. Indicators of Insider Risk
- Large file downloads
- External uploads
- Unusual VPN activity
- Access outside business hours

### 3. Containment
- Restrict access
- Block external sharing
- Disable user temporarily

### 4. Investigation
- Review file access patterns
- Check proxy logs
- Validate business justification

### 5. Recovery
- Restore access if legitimate
- Implement least privilege
- Add monitoring

### 6. Reporting
- Document findings
- Recommend controls

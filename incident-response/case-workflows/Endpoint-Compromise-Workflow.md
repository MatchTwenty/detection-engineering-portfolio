# Endpoint Compromise Workflow

## Objective
Investigate malware, persistence, lateral movement, or suspicious endpoint behavior.

## Steps

### 1. Initial Triage
- Review Defender alerts
- Identify suspicious processes
- Check network connections

### 2. Forensic Collection
- Memory capture
- Process list
- Network connections
- Prefetch files
- Event logs

### 3. Indicators of Compromise
- Persistence mechanisms
- Credential theft tools
- Remote access tools
- Suspicious scheduled tasks

### 4. Containment
- Isolate device
- Block malicious hashes
- Disable compromised accounts

### 5. Investigation
- Analyze memory dump
- Review file system artifacts
- Check for lateral movement
- Review cloud identity activity

### 6. Recovery
- Reimage device
- Restore data
- Re-enroll device in MDM

### 7. Reporting
- Document findings
- Provide RCA
- Recommend controls

# Cloud Security Detections

This folder contains detections focused on Azure and Microsoft 365 cloud environments. These detections identify anomalous identity behavior, cloud reconnaissance, and suspicious administrative activity.

## Included Detections

- **Cloud Identity Anomalies**

## Data Sources

- Azure AD Sign-In Logs  
- Entra ID Audit Logs  
- Unified Audit Log  
- Sentinel Analytics

## MITRE ATT&CK Coverage

- **T1087 — Account Discovery**  
- **Discovery Tactics**

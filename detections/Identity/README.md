# Identity Detections

This folder contains detections focused on identity misuse, authentication anomalies, and account-based threats. These detections help identify credential theft, unauthorized access, suspicious sign-in patterns, and identity compromise.

## Included Detections

- **Suspicious Application Registration**  
- **Identity Misuse Detection**  
- **VPN Connection Previously Unseen by User**

## Data Sources

- Azure AD Sign-In Logs  
- Entra ID Audit Logs  
- Conditional Access Logs  
- Identity Protection Signals

## MITRE ATT&CK Coverage

- **T1078 — Valid Accounts**  
- **T1098.003 — Additional Cloud Credentials**

# Privilege Escalation Detections

This folder contains detections related to unauthorized privilege elevation, role assignment abuse, and IAM manipulation. These detections help identify high-risk changes to administrative roles and permissions.

## Included Detections

- **Unauthorized Role Assignment**

## Data Sources

- Entra ID Audit Logs  
- Directory Role Management Events

## MITRE ATT&CK Coverage

- **T1069.003 — Permission Groups Discovery (Cloud)**  
- **Privilege Escalation Tactics**
